# Transecto Climático

Site que junta o arquivo de um termohigrômetro com o trajeto de uma caminhada (KML, KMZ ou GPX) e mostra no mapa como a temperatura e a umidade mudaram ao longo do caminho.

Acesse: https://guedeszx1.github.io/transecto-climatico/

Os arquivos são processados no navegador de quem usa e não são enviados a nenhum servidor. O exemplo incluído usa dados fictícios.

Desenvolvido por Rafael Guedes, LCGEA, Universidade de Brasília (UnB).

Usa Leaflet, JSZip, SheetJS e a fonte Archivo. Mapas de fundo: OpenStreetMap e Esri.
